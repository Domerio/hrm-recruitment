# 从工作台定位 BOSS 收藏牛人

候选人列表和详情提供「收藏中定位」。工作台记录编号只用于选择档案，不会作为 BOSS 候选人编号。

## 使用

1. 在准备使用插件的电脑上，用 Edge 或 Chrome 打开工作台。其它电脑请使用服务器的局域网 IP，例如 `http://<服务器IP>:8765/`；服务器本机也可使用本地地址。
2. 在「连接与集成」下载并安装插件。ZIP 自动带入当前访问地址，无需填写 IP。打开插件，点击「连接工作台」并允许浏览器访问该服务器，再复制本浏览器的扩展 ID，到本页点击「授权连接」。不要把从 `127.0.0.1` 页面下载的安装包直接给其它电脑使用。
3. 在已登录 BOSS 的同一浏览器打开候选人列表或详情，点击「收藏中定位」。已有访问权限时，档案读取成功后自动开始查找；尚无工作台访问权限时，先点击「连接并读取档案」并允许访问，再点击「开始定位」。若尚未授权访问 BOSS，按页面提示从 BOSS「互动 → 收藏牛人」页面的插件入口打开。
4. 找到线索后临时打开简历核验，核验通过后返回收藏列表，将对应卡片滚动到视口并描边标注。只有卡片实际可见才显示定位成功。

从扩展菜单手动输入候选人编号时，仍需点击「读取档案」和「开始定位」。修改编号后必须重新读取，不能沿用上一人的档案。

定位不进行 AI 评估，不点击「联系Ta」「打招呼」、转发或取消收藏。定位后可自行使用卡片上的联系入口。收藏状态本身不证明已经建立沟通关系。未找到或匹配冲突直接在 BOSS 页面提示，不将打开收藏页当作定位完成。

## 匹配

- 优先使用已核验的平台身份标识。
- 没有平台身份时，姓名须与多个独立职业经历线索匹配。卡片公司简称仅去除法定公司后缀，用于初筛；至少两条公司及对应任职时间、学校相符后，仍须在简历详情核对正式公司全称及同条日期，才能保存关联。脱敏姓名、任意单个公司关键词或日期都不能单独确认身份。
- 冲突、多个可能匹配、页面变化、切换账号或停止操作均不应继续打开另一个人。
- 查找范围受当前账号可见收藏、平台筛选及扫描上限约束；未找到不等于候选人不存在。

## 连接范围

当前版本支持本机和局域网工作台。收藏链接中的工作台来源必须与插件安装包的连接地址一致，地址不一致时不会读取档案或请求访问权限。链接只携带工作台记录编号和来源，不含履历、姓名或访问令牌。

工作台可同时授权多个扩展 ID，每个浏览器需记录自己的 ID。局域网浏览器首次访问时不会自动采用已授权的其它 ID；解除授权只影响当前浏览器选定的 ID。若插件目录或浏览器更换导致 ID 改变，请重新授权当前 ID。

### 历史连接方式（0.5.116 及以前）

旧版扩展沿用本机工作台连接。局域网网页可以浏览候选人，但收藏定位需要在工作台主机上的已配对浏览器使用，防止将另一台电脑的同号记录当作同一档案。
