# 高分候选人自动打招呼

工作台 0.5.67，采集扩展 0.5.114。

## 规则

在采集窗口勾选「高分自动打招呼」后，推荐牛人的正常采集会在收藏、已启用的转发和二维码保存完成后，使用当前 BOSS 招聘账号已配置的默认招呼语。打招呼与站内转发共用 `share_above` 分数线，均要求评分**严格高于**门槛；分数刚好等于门槛不会发送。转发与打招呼分别开关，关闭其中一项不会关闭另一项。

候选人必须已归档、AI 评估成功且仍适用于当前简历及岗位、分数同时高于保存分数线、收藏已确认。旧档案只在当前推荐列表重新遇到且核验一致时补做，不在后台遍历库中候选人。修改本次共用门槛会影响本次打招呼资格；已有转发待办继续使用原保存策略。

旧设置默认关闭自动打招呼，升级不会自动启动采集。仅补采聊天入口、单份简历评估、搜索页采集都不会发送招呼。

## 身份与结果确认

点击前核验当前招聘账号、推荐卡片、简历姓名、加密候选人标识、数值 UID、详情框架和岗位。仅操作详情中唯一可确认的官方「打招呼」控件；已有好友关系时不点击。需要选岗、确认购买、人工验证或无法绑定身份时暂停，由人工处理。

先由本地工作台原子保存一次发送尝试，收到本次许可后才点击。工作台按招聘账号与候选人 UID 防重，跨岗位、重复档案、重新加载扩展和服务重启均保留记录。点击后只在当前绑定详情明确确认关系后记录成功；超时、关闭窗口、停止、账号切换或结果丢失不会自动重发。

工作台「联系候选人」会按招聘账号显示确认过的关系及打开会话入口；结果不明的尝试显示待核对。仍须使用对应招聘账号登录 BOSS，平台当前权限决定是否能打开会话。

## 实现边界

使用现有官方页面按钮，未重放 BOSS 的打招呼接口，没有新增调试器或 DevTools 调用，不读取招呼正文、Cookie、请求头或授权参数。默认招呼内容由 BOSS 账号配置决定，工作台不生成或改写消息。

前端和后端使用同一 `greet_enabled` 开关和 `share_above` 阈值；新增开关不改变既有低分采集标记的策略指纹，避免仅启用打招呼就重新付费分析低分候选人。
